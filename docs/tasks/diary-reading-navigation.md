# 日記閱讀導覽

## 任務說明

在保留最新到最舊的左側日記索引之下，讓 About 作為序章，並在正文結尾提供連續閱讀的上一則／下一則導覽。

## 取代現況

首頁只有文章索引與單篇切換，About 沒有銜接第一篇日記，文章正文結尾也沒有連續閱讀入口。

## 設計意圖

目錄服務快速追蹤最新內容；文章導覽則服務從 About 開始連續閱讀的讀者。兩套排序互相獨立，避免犧牲既有索引可見性。

## 做法

- 保留左側索引的最新→最舊排序。
- 以同一批 Jekyll entries 的反向順序建立閱讀序列。
- About 增加「開始閱讀」連到最舊日記。
- 每篇日記在正文結尾自動產生相鄰導覽。
- 導覽點擊沿用 SPA 切換、`history.pushState` 與手機捲動重置。

## 影響範圍

- `index.html`：導覽標記、樣式與 SPA 點擊橋接。
- `README.md`：更新閱讀與手機操作說明，移除過時的抽屜關閉控制說明。
- `_layouts/diary.html`：維持既有直接網址導回首頁行為。

## 驗證方式

- Jekyll 使用 `--disable-disk-cache` 建置。
- 檢查 About、最舊、中間、最新文章的導覽邊界。
- 驗證導覽點擊後標題、URL、active 狀態與捲動位置。
- 驗證手機 Drawer、桌機雙欄、Back／Forward 與無水平捲動。
- 執行 `git diff --check` 與過時抽屜控制掃描。

## 回滾方式

修改保留在功能分支；若驗證失敗，停止合併推送，使用該分支的反向 patch 還原本次變更。
